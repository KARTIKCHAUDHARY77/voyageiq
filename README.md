## About

VoyageIQ AI is a production-grade maritime SaaS platform for intelligent vessel performance monitoring and voyage optimization. Built by **Kartik Chaudhary**.

### Features
- 🚢 Real-time Vessel Performance Monitoring
- 🗺️ AI-powered Voyage Optimization
- ⛽ Advanced Fuel Analytics
- 🌊 Weather Intelligence (Headwind/Tailwind/Current Analysis)
- 🤖 AI Copilot (GPT-4 powered)
- ⚖️ Automatic Claim Detection
- 📊 Executive Reporting (PDF/Excel/CSV)

## Tech Stack

**Frontend:** React 18, TypeScript, Tailwind CSS, Vite, Leaflet Maps, Chart.js, Framer Motion  
**Backend:** Python Flask, SQLAlchemy, PostgreSQL, JWT Auth  
**AI:** OpenAI GPT-4, Rule-based maritime intelligence engine  
**Deploy:** Vercel (Frontend) + Render (Backend)
